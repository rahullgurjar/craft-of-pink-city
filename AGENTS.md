# Workspace Rules & Operating Guidelines

## Direct Website Implementation
- **Always Implement on Website**: Whenever any change, feature, fix, or improvement is discussed, designed, or requested, always directly implement and modify the active website codebase files (`src/`, `public/`, etc.).
- **Verify with Build**: Always verify that changes compile cleanly by running `npm run build` and ensure dev server components render properly without broken imports or runtime errors.
- **Never Leave Changes Only in Scratch/Mock Files**: All functional and visual updates must be directly reflected on the live website.
